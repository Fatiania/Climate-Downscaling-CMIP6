# Climate Downscaling and CMIP6 Projections

Statistical downscaling and evaluation of climate-model data, with applications to hydroclimatic analysis in Morocco.

## Methods
- Historical calibration and validation of climate-model predictors
- Processing of MIROC6 climate scenarios
- Statistical downscaling and bias-adjustment approaches
- Evaluation of climate variables and derived hydroclimatic indicators

## Source files
- `src/classical_downscaling.py`: statistical downscaling analysis
- `archive/cmip6_miroc6_earlier_calibration.py`: alternative calibration configuration

## Data
Climate-model outputs and reference datasets are maintained separately. The original analyses use project-specific input directory configurations.
